# reviewMode — diffcon context float + reviewer agent

<!-- inclusion: manual -- load when working on reviewMode.lua or the cc context float. -->

`lua/addons/reviewMode.lua` is the older review helper that predates `vreview`. It
is still active: `vreview.setup()` calls `require('addons.reviewMode').setup()`, so
the two coexist. It provides two things.

## 1. The `cc` diffcon-context float

In diff/diffview buffers, `cc` shows a floating window with the human-written
explanation for the change under the cursor, sourced from a
`llm_diff_context.diffcon` file (generated by the `review-cr-code` skill).

- **diffcon format**: `path/to/File:START-END | explanation` per line; `#` lines are
  comments. Lines refer to the **new** file side.
- **Discovery**: searches upward for `llm_diff_context.diffcon` from cwd, then from
  the buffer's real path (stripping the `diffview://` prefix), so it works on both
  panes regardless of cwd.
- **Line matching** (`find_context_for_line`):
  1. New-file (right) buffer → direct line-in-range match.
  2. Old-file (left) buffer → parse `git diff <base>` hunks to map old-line → new
     line range, then match. Base ref is detected from the `CRUX/CR-*/rN/<base>`
     branch name, else `HEAD~1`.
  3. Proximity fallback → nearest entry within 5 lines.
- **Float behavior**: first `cc` opens the float (cursor stays put); second `cc`
  jumps into it to scroll; `q`/`<Esc>` close it; moving the cursor in the parent
  buffer auto-closes it. Text is word-wrapped to ~72 cols, filetype `markdown`.

## 2. Background code-reviewer agent

On `setup()`, if the cwd is a CR workspace (`~/workspace/brazil/CR-XXXXXXXX/…`), it
starts the `claude-code` "review" variant terminal in a temporary tab, then hides
it (survives via `bufhidden=hide`) so it's instantly available later. Guarded by
`pcall(require, "claude-code")` so it's a no-op when that plugin is absent.

## Setup details

- Sets `vim.g.review_mode = true`.
- A `BufEnter` autocmd binds `cc` in diff/DiffviewFiles/review-mode buffers. (Note:
  `vreview.init` also delegates the `cc` binding here — don't duplicate it.)

## Relationship to vreview

`vreview` is the newer, broader system (comments, panels, order window). reviewMode
is narrower and read-only (context display). Keep the `cc` behavior here; put new
review features in `vreview`. See `vreview.md`.
